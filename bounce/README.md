# Bounce

Bounce some text

## Configuration

ENV variables:

APP_TEXT_NAME - module name, default: `bounce`
APP_TEXT_PUBSUBURL - nats url, default: `nats://127.0.0.1:4222` 
APP_TEXT_KIGONAME - KiGo pub sub topic, defautl: `KiGo`

## Changes

Changes allowed during the lifecycle

- Text - change text
